# SimplePush App

Простое Android приложение для получения push-уведомлений и ссылок с сервера.

## Описание

SimplePush - это мобильное приложение на Kivy, которое:
- Автоматически регистрирует устройство на сервере
- Получает ссылки с сервера и открывает их в браузере
- Показывает уведомления и вибрацию
- Имеет современный темный интерфейс

## Функциональность

- 🔄 Автоматическая регистрация устройства при запуске
- 🔗 Получение ссылок с сервера
- 🌐 Открытие ссылок в браузере
- 📱 Уведомления и вибрация
- 🎨 Современный темный интерфейс

## Технологии

- **Python 3** - основной язык программирования
- **Kivy 2.3.2** - фреймворк для создания мобильных приложений
- **Buildozer** - инструмент для сборки Android APK
- **Requests** - для HTTP запросов
- **Plyer** - для доступа к системным функциям (уведомления, вибрация)

## Требования

### Для разработки:
- Python 3.7+
- Buildozer
- Android SDK и NDK

### Для установки APK:
- Android 5.0+ (API 21+)

## Установка и сборка

### 1. Клонирование репозитория
```bash
git clone https://github.com/YaroslavKuchko/SimplePushApp.git
cd SimplePushApp
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
pip install buildozer
```

### 3. Сборка APK
```bash
buildozer android debug
```

Готовый APK будет в папке `bin/`.

## Автоматическая сборка

Проект настроен для автоматической сборки APK через GitHub Actions при создании тега:

```bash
git tag v1.0.0
git push origin v1.0.0
```

APK будет автоматически собран и загружен в релиз.

## Конфигурация

Основные настройки приложения находятся в `buildozer.spec`:

- Название приложения: `SimplePush`
- Пакет: `org.example.simplepush`
- Минимальная версия Android: API 21 (Android 5.0)
- Целевая версия Android: API 33 (Android 13)

## Сервер

Приложение работает с сервером по адресу: `http://138.124.113.77:8000`

Эндпоинты:
- `POST /register_device` - регистрация устройства
- `GET /get_link` - получение ссылки
